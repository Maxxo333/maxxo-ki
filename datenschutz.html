Maxxo KI Mobil

Datenschutzhinweise

Stand: November 2026

Kurz gesagt

Maxxo KI Mobil ist eine reine Web-App ohne eigenen Server. Es gibt kein Tracking, keine Analyse-Werkzeuge, keine Werbung und keine Cookies.

Was auf deinem Gerät bleibt

  • Deine Unterhaltungen, deine Einstellungen und deine API-Schlüssel werden nur im Speicher dieses Browsers (localStorage) auf diesem Gerät abgelegt.
  • Du kannst sie jederzeit in den Einstellungen löschen („Gesamten Verlauf löschen“, „Schlüssel löschen“ oder „Alles löschen“).
  • Wer dein entsperrtes Gerät benutzt, könnte diese Daten im Browser einsehen.

Was an wen gesendet wird – nur wenn du eine Frage stellst

  • Anthropic (Claude): der Verlauf der aktuellen Unterhaltung, deine Frage und – bei einer Websuche – die gefundenen Suchausschnitte. Die Anfrage wird mit deinem Claude-Schlüssel direkt an api.anthropic.com gesendet. Es gelten die Datenschutzbestimmungen von Anthropic.
  • Tavily (Websuche): nur die kurze Suchanfrage, falls eine Suche nötig ist und ein Tavily-Schlüssel eingetragen ist. Offensichtliche persönliche Daten (E-Mail-Adressen, Telefonnummern, IBANs) werden vorher entfernt. Es gelten die Datenschutzbestimmungen von Tavily.
  • Darüber hinaus werden keine Daten an Dritte gesendet.

Hosting

Die Dateien dieser App werden von GitHub Pages ausgeliefert. Beim Abruf der Seite kann GitHub technische Zugriffsdaten (z. B. IP-Adresse, Zeitpunkt) verarbeiten und protokollieren – siehe die Datenschutzerklärung von GitHub. Deine Unterhaltungen und Schlüssel erreichen GitHub nicht.

Grenzen

Maxxo KI kann Fehler machen. Prüfe wichtige Informationen anhand der Quellen. Die App ersetzt keine fachliche Beratung.
